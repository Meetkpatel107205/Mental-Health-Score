# 🧠 Mental Health Signal — Student Wellness Analytics

A machine learning web application that predicts a student's mental health score on a scale of **0–10** based on academic habits, digital behavior, lifestyle patterns, and perceived stress.

## 🌐 Live Demo

https://mental-health-score-85zu.onrender.com/

## ✨ Features

- 🧠 Mental health score prediction using machine learning
- 👤 Student demographic and academic inputs
- 📱 Social media and digital usage analysis
- 😴 Study hours, sleep, and physical activity tracking
- 📊 Perceived stress level analysis
- 📈 Interactive score visualization
- ✅ Client-side and server-side input validation
- ⚡ REST API built with FastAPI
- 🚀 Deployed on Render

## 🛠️ Tech Stack

- **Machine Learning:** Python, Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Model Persistence:** Joblib
- **Backend:** FastAPI
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render

## 📋 Input Parameters

The model uses the following factors for prediction:

- Age
- Gender
- Country
- Academic Level
- Most Used Social Media Platform
- Primary Purpose of Social Media Usage
- Average Daily Screen Time
- Daily Phone Unlocks
- Study Hours
- Physical Activity Hours
- Sleep Hours per Night
- Perceived Stress Level
